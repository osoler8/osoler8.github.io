# 🧮 Descomposició de Multiplicacions - Mètode de la Caixa

Una aplicació web interactiva per aprendre la descomposició de multiplicacions utilitzant el mètode de la caixa (també conegut com a mètode rectangular).

## 🌟 Característiques

- **Interfície intuïtiva**: Camps d'entrada simples per introduir els números a multiplicar
- **Graella interactiva**: Genera automàticament la taula de descomposició
- **Ajuda pas a pas**: Botó d'ajuda que guia l'estudiant a través de cada pas
- **Validació en temps real**: Comprova les respostes i mostra feedback visual
- **Responsive**: Funciona perfectament en dispositius mòbils i tauletes
- **Solució automàtica**: Opció per mostrar la solució completa

## 🚀 Com usar l'aplicació

1. **Introdueix els números**: Escriu dos números als camps d'entrada
2. **Genera la graella**: Fes clic al botó "Generar Graella"
3. **Omple manualment**: Pots escriure els resultats a cada casella
4. **Usa l'ajuda**: El botó "Ajuda Pas a Pas" t'anirà mostrant cada multiplicació
5. **Verifica**: L'aplicació calcularà automàticament el resultat final

## 📱 Configuració per GitHub Pages

### Pas 1: Crear el repositori
1. Crea un nou repositori a GitHub
2. Puja aquests fitxers al repositori:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `README.md`

### Pas 2: Activar GitHub Pages
1. Ves a la configuració del repositori (Settings)
2. Baixa fins a la secció "Pages"
3. A "Source", selecciona "Deploy from a branch"
4. Selecciona la branca "main" i la carpeta "/ (root)"
5. Fes clic a "Save"

### Pas 3: Accedir a l'aplicació
Després d'uns minuts, l'aplicació estarà disponible a:
`https://[el-teu-usuari].github.io/[nom-del-repositori]`

## 🎯 Exemple d'ús

Per multiplicar 28 × 5:

1. **Descomposició**: 28 = 20 + 8, i 5 = 5
2. **Graella**:
   ```
   |    | 20  | 8   |
   |----|----|-----|
   | 5  | 100 | 40  |
   ```
3. **Resultat**: 100 + 40 = 140
